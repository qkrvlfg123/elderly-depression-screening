# 사랑방 자서전, 우울 위험 선별 모델

고령자 구술 텍스트에서 우울 위험군을 선별하는 텍스트 분류 파이프라인. 데이터 정리, 학습, 평가, 추론 API 서버를 담음.

- 팀 프로젝트(팀 그랜:토리, 2026.08.03~2026.08.12)임. 이 저장소는 그중 데이터 분석 파트의 코드이고, 서비스의 나머지 부분(구술 녹화, 숏폼과 자서전 제작, 가족 전달)은 팀 전체 작업이며 여기에 없음.
- 수치는 `results/`의 JSON 파일에 있는 값임. 발표 당시 수치처럼 파일이 없는 값에는 (기록)을 붙임.
- 실제 서비스 사용자의 발화로는 성능을 시험하지 못함. 아래 수치는 전부 공개 데이터의 평가용 화자 1,164명 기준임.
- 서비스 데모: https://sarangbang-autobiography.vercel.app

## 배경

- 사랑방 자서전은 고령층이 매일 질문 하나에 말로 답하면 그 영상이 숏폼과 자서전으로 만들어지는 서비스임.
- 이 과정에서 쌓이는 발화 텍스트로 우울 신호를 관찰해 가족에게 전달하는 보조 기능을 두었고, 이 저장소는 그 선별 모델 부분임.
- 목적은 진단이 아니라 관찰과 상담 권유임. 자서전과 회고가 주 기능이고 정서 관찰은 보조 기능임.

| 화자 수 | 화자 단위로 통합한 5,823명 중, 키워드마다 우울점수가 다르게 기록된 4명을 빼고 5,819명 |

- 화자별 예측 파일(`results/preds/`)은 AI-Hub 화자 ID와 연결된 모델 출력이라 저장소에 올리지 않음.

## 방법

### 모델

4개 모델의 확률을 평균하는 앙상블.

| 모델 | 손실 | 입력 | 학습 |
|---|---|---|---|
| KoBigBird_1234_f | Focal (γ=2) | 3,072토큰, 6,000자 × 최대 5청크 | lr 1e-5, 배치 1 × 누적 16, 5 epoch |
| KoBigBird_2222_f | Focal (γ=2) | 3,072토큰, 6,000자 × 최대 5청크 | lr 1e-5, 배치 1 × 누적 16, 5 epoch |
| KLUE-RoBERTa_888 | BCE | 512토큰, 800자 × 최대 8청크 | lr 2e-5, 배치 16, 5 epoch |
| KLUE-BERT_42 | BCE | 512토큰, 800자 × 최대 8청크 | lr 2e-5, 배치 16, 5 epoch |

- 모델 이름의 숫자는 시드, `_f`는 Focal 손실임. 위험군 가중치(pos_weight)는 5.
- 화자 텍스트를 문장부호(. ! ?) 경계에서 청크로 나누고, 화자 확률은 청크 확률의 평균으로 계산함.
- 한국어는 토큰당 약 2자라서 청크가 토큰 상한 안에 들어가도록 글자 수를 맞춤.

### 파이프라인

```
JSON 원본 (AI-Hub 71703)
      |
      v  00_make_speakers_csv.py     화자별 통합, PHQ-2/GAD-2와 인구통계 정리
speakers.csv
      |
      v  01_preprocess_kssds.py      KSSDS 문장 분리
speakers_clean_kssds.csv
      |
      v  02_train_final.py           4모델 학습 (5 epoch, epoch별 평가 예측 저장) -> results/repro_final4.json
      v  03_evaluate_final.py        서빙 구성(ensemble.json) 작성, 평가 -> results/final_serving.json
      |- 05_baseline.py              기준 모델(인구학, TF-IDF) 비교, 5겹 교차검증 -> results/baseline_cv.json
      v  04_serve_api.py             FastAPI 앙상블 서버 (위험도, 보정, 행복지수, 3단계 등급)
POST /predict -> {"risk_score": 0.32, "happiness_index": 68, "grade": "안정", ...}
```

### 서빙과 등급

- 모델 평균 점수를 0.50~0.78 구간에서 0~1로 펴서 위험도로 씀.
- 위험도 0.5 이상은 상담 권유, 0.4 이상은 관찰, 그 아래는 안정.
- 행복지수는 위험도를 뒤집어 0~100으로 표시한 값임.
- 보정 구간과 등급 기준은 시연 문장으로 정한 초기값임. 데이터로 조정한 값이 아님.
- 입출력 형식은 [`docs/API명세.md`](./docs/API명세.md)에 있음.

### 평가

- 서빙(`04_serve_api.py`)과 같은 처리로 평가함(`src/03_evaluate_final.py`).
- 입력 길이를 두 가지로 봄. 화자의 전체 텍스트, 그리고 답변 1개 분량인 앞 800자.
- 신뢰구간은 평가 화자를 2,000회 재표집한 부트스트랩 95% 구간임.
- 기준 모델은 설정을 하나로 고정했고 평가 데이터를 보고 고른 값이 없음(`src/05_baseline.py`).

## 결과

### 배포 모델 (평가 화자 1,164명)

| 모델 | AUROC, 전체 텍스트 | AUROC, 앞 800자 |
|---|---|---|
| KoBigBird_1234_f | 0.647 | 0.599 |
| KoBigBird_2222_f | 0.647 | 0.598 |
| KLUE-BERT_42 | 0.625 | 0.567 |
| KLUE-RoBERTa_888 | 0.587 | 0.521 |
| 4모델 앙상블 | 0.661 (0.625~0.697) | 0.604 (0.564~0.644) |
| 4모델 앙상블, 위험군 기준 3점 이상 | 0.668 (0.617~0.717) | 0.599 (0.541~0.653) |

- 서비스 입력은 하루 답변 1개임. 서비스에서 기대할 성능은 800자 열에 가까움.
- 상세 수치는 `results/final_serving.json`에 있음.

### 등급별 결과 (위험군 기준 2점 이상)

| 입력 | 안정 / 관찰 / 상담 권유 비율 | 상담 권유: 재현율 / 정밀도 / 특이도 | 관찰 이상: 재현율 / 정밀도 / 표시 비율 |
|---|---|---|---|
| 전체 텍스트 | 72.1% / 12.3% / 15.6% | 0.260 / 0.368 / 0.873 | 0.415 / 0.329 / 27.9% |
| 앞 800자 (답변 1개) | 65.6% / 10.5% / 23.9% | 0.341 / 0.317 / 0.790 | 0.450 / 0.290 / 34.4% |

- 800자 입력에서 상담 권유는 전체의 약 24%에 표시되고, 그중 실제 위험군은 32%임(무작위로 고르면 22%). 위험군의 34%를 잡음.

### 기준 모델 비교

| 모델 | 평가 AUROC (95% CI) | 5겹 교차검증 (겹마다 재학습) |
|---|---|---|
| 인구학 변수만 (나이, 성별, 교육, 로지스틱 회귀) | 0.564 (0.521~0.604) | 0.542 ± 0.012 |
| 글자 2~3-gram TF-IDF + 로지스틱 회귀 | 0.645 (0.607~0.682) | 0.630 ± 0.014 |
| 4모델 앙상블 | 0.661 (0.625~0.697) | 계산하지 않음 |

- 앙상블과 TF-IDF의 차이는 +0.016이고, 같은 화자를 재표집한 95% 구간은 -0.015~+0.047로 0을 포함함. 이 데이터에서 트랜스포머 앙상블이 TF-IDF 모델보다 낫다고 보기 어려움.
- 인구학 변수만으로는 무작위(0.5)에 가까움. 성능의 대부분은 텍스트에서 옴.

### 발표 수치(0.674)와의 관계

발표 때는 별도 검증 데이터 없이 평가 점수로 모델마다 epoch을 고르고, 학습한 여러 모델 중 평가 점수가 가장 높은 4개 조합을 골랐음. 그래서 위 결과는 낙관적인 값임. 이를 확인하려고 같은 데이터, 분할, 설정으로 4모델을 다시 학습하고 epoch마다 평가 예측을 저장함(`src/02_train_final.py`, `results/repro_final4.json`).

재학습 epoch별 평가 AUROC

| 모델 | ep1 | ep2 | ep3 | ep4 | ep5 |
|---|---|---|---|---|---|
| KoBigBird_1234_f | 0.584 | 0.606 | 0.632 | 0.643 | 0.645 |
| KoBigBird_2222_f | 0.582 | 0.593 | 0.624 | 0.636 | 0.642 |
| KLUE-RoBERTa_888 | 0.556 | 0.587 | 0.568 | 0.592 | 0.586 |
| KLUE-BERT_42 | 0.612 | 0.629 | 0.608 | 0.593 | 0.574 |

4모델 앙상블 AUROC

| 구분 | 값 | 평가 데이터로 고른 것 |
|---|---|---|
| 발표 수치 (실험 때 저장한 예측, 기록) | 0.674 | epoch, 4개 조합 |
| 배포 모델 (위 결과) | 0.661 | epoch, 4개 조합 |
| 재학습, 평가 점수로 epoch 선택 | 0.659 (0.622~0.695) | epoch |
| 재학습, epoch 5 고정 | 0.641 (0.603~0.677) | 없음 (조합은 최종본을 따름) |

- epoch을 미리 정한 값(0.641)이 평가 데이터로 고르지 않은 성능에 가장 가까움.
- 발표 수치는 실험 때 저장한 예측 파일로 계산했고 배포 가중치는 따로 학습한 것이라 0.013 차이가 남. KLUE-RoBERTa_888이 0.646에서 0.587로 가장 크게 달라짐.
- 이전 README의 5겹, 10겹 수치(0.675, 0.672)는 재학습 없이 같은 평가 예측을 나눠 평균한 값이라 교차검증이 아니어서 뺌.

## 한계

- 실제 서비스 사용자의 발화로 시험하지 못함. 새로운 화자에서의 성능은 별도 데이터로 확인해야 함.
- epoch과 앙상블 조합을 평가 데이터로 골랐기 때문에 0.661은 낙관적인 값임. epoch을 미리 정해 재학습하면 0.641.
- 같은 평가 데이터에서 TF-IDF 기준 모델이 0.645로, 앙상블과의 차이가 통계적으로 뚜렷하지 않음.
- 답변 1개 분량(800자) 입력에서는 AUROC 0.604이고, 상담 권유 등급은 약 24%에 표시되는 대신 위험군의 약 34%만 잡음.
- 점수 보정 구간(0.50~0.78)과 등급 기준(0.4, 0.5)은 시연 문장으로 정한 초기값임. 보정 후 0.4~0.5 구간이 원점수 0.612~0.64로 좁아 관찰 등급은 약 10%에 그침.
- 라벨은 PHQ-2 유사 선별 문항의 자가보고이며 의학적 진단이 아님.
- 구술 데이터는 과거 회상 중심이라 현재의 우울 상태를 예측하는 데 구조적 한계가 있음. 음성과 표정을 함께 쓰는 확장은 계획만 있고 착수하지 않음.
- 의료기기가 아니며 진단을 내리지 않음.

## 기술 스택

- 언어: Python 3.12 이상
- 모델: PyTorch, Transformers (KoBigBird, KLUE-BERT, KLUE-RoBERTa), scikit-learn(기준 모델)
- 서빙: FastAPI, Uvicorn, pydantic
- 전처리: KSSDS

## 실행 방법

AI-Hub에서 데이터셋 71703을 받아야 함.

```bash
pip install -r requirements.txt

# 0) JSON 원본에서 화자별 통합 CSV 생성
python src/00_make_speakers_csv.py --json-dir ./json --out speakers.csv

# 1) KSSDS 문장 분리
python src/01_preprocess_kssds.py --in speakers.csv --out speakers_clean_kssds.csv

# 2) 4모델 학습. 끝난 모델은 건너뜀. 결과는 saved_models/repro/<모델>/
python src/02_train_final.py --csv speakers_clean_kssds.csv

# 3) 서빙 구성 작성과 평가. 배포 가중치 4개를 saved_models/final/<모델>/ 에 둠
python src/03_evaluate_final.py --csv speakers_clean_kssds.csv

# 4) API 서버
python src/04_serve_api.py
# POST http://localhost:8000/predict  {"text": "..."}

# 5) 기준 모델 비교. 3) 다음에 실행하면 최종본과 짝지어 비교함
python src/05_baseline.py --csv speakers_clean_kssds.csv
```

- 걸리는 시간(RTX 4070 기준, 기록): 학습은 KoBigBird 모델당 약 7시간, KLUE 계열 약 1시간. 평가 약 30분. 기준 모델 비교 약 5분.
